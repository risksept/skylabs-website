# Skylabs Indonesia — Website & Privacy Policy Hub

Website profil studio pengembang independen **Skylabs Indonesia** sekaligus rumah dokumentasi dan Kebijakan Privasi resmi (*Privacy Policy*) untuk aplikasi **EXAM**, **SimplePOS**, dan **eling**.

## 📁 Struktur Direktori
- `index.html`: Halaman utama, katalog proyek, dan dokumentasi statis + Kebijakan Privasi (Clean Light Theme).
- `assets/`:
  - `skylabs-cloud-blue.png`: Logo resmi transparent cloud mark Skylabs Studio.
  - `exam-logo.png`: Ikon resmi aplikasi desktop EXAM (Coretax DJP & Pemda).
  - `eling-logo.png`: Ikon resmi 3D brand mark aplikasi eling.
  - `simplepos-logo.png`: Ikon resmi kasir SimplePOS.
  - `favicon.png`: Favicon web browser.

## 🚀 Cara Deploy ke Cloudflare Pages (Gratis Selamanya, Tanpa Beli Domain)

Anda tidak perlu membeli domain berbayar. Cloudflare menyediakan subdomain gratis `*.pages.dev` dengan SSL otomatis dan server CDN super cepat di Jakarta.

### Langkah-langkah:
1. Buka browser dan login ke **[Cloudflare Dashboard](https://dash.cloudflare.com/)**.
2. Di menu navigasi samping kiri, pilih **Workers & Pages**.
3. Klik tombol **Create application** > Pilih tab **Pages**.
4. Pilih opsi **Upload assets** (Direct Upload).
5. Masukkan nama proyek Anda, misalnya: `skylabs` (hasil URL Anda akan menjadi: `https://skylabs.pages.dev`).
6. Seret (*drag & drop*) seluruh folder `skylabs-web` ini ke dalam kotak upload Cloudflare.
7. Klik **Deploy site**.

Selesai! Dalam 10 detik website Anda sudah resmi online di seluruh dunia! 🎉
